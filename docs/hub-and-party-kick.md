# Hub & party kick (context menu)

Right-click a player name to open a parchment context menu; left-click does **not** kick.

## Hub roster (“In hub”)

- **UI:** `apps/web/src/game/ui/HubRoster.tsx`
- **Who can kick:** hub owner only, not self, not the hub owner row
- **Client message:** `hub_kick` `{ sessionId }`
- **Server:** `BaseCityRoom.handleHubKick` — disconnects the visitor from this hub room
- **Menu label:** “Kick {name} from lobby”

## Arena party lobby

- **Open party:** Opening the PvP party lobby pulls **everyone already in the hub** onto the party screen (auto-members). No in-hub invites required.
- **Invite Friend:** Same as Friends → Invite to hub. Marks the friend pending on the party; when they accept and join the hub, they auto-enter the party lobby.
- **UI:** `apps/web/src/game/ui/PartyLobbyPanel.tsx`
- **Who can kick:** party leader only, while not queued, not self
- **Client message:** `party_kick` `{ sessionId }` via `kickFromParty` in `useBaseCityRoom.ts`
- **Server:** `BaseCityRoom.handlePartyKick` — removes member, clears their `party_update`, may unqueue the party
- **Menu label:** “Kick {name} from lobby”

## Context menu styling

Shared classes in `apps/web/src/styles/game-hud.css`:

- `.bb-context-menu` — fixed parchment panel at cursor
- `.bb-context-menu__item` / `--danger` — menu actions

Menus close on outside pointerdown, Escape, or scroll.

## Desktop app — what not to commit

Commit Electron **source** under `apps/desktop/` (`main.cjs`, `preload.cjs`, `package.json`, `scripts/`, `config.example.json`, `README.md`).

**Do not commit** (gitignored):

| Path | Why |
| --- | --- |
| `apps/desktop/release/`, `release-v*/` | Packaged Windows builds (~hundreds of MB) |
| `apps/desktop/renderer/` | Copied web build output; regenerated by `build:renderer` |
| `apps/desktop/config.json` | Local game-server URL override (use `config.example.json`) |
| `apps/desktop/node_modules/` | Dependencies |
| `apps/bb.zip` | Ad-hoc zip of builds |

Friends get a fresh portable build via `pnpm --filter @battlebeasts/desktop dist` (output dir is currently `release-v5` per `package.json` `build.directories.output`).
